CONTRACT — output exactly ONE JavaScript program, nothing else (no markdown fences, no prose). It must assign:
window.FX_TOP = [ { name: 'Classic', height: <px int>, css: `<scoped CSS string>`, render(bar, ctx, signal) {...} }, { name:'Glass', ...}, { name:'Row', ...} ];
- `bar` is an empty absolutely-positioned <header> spanning the top of the document area (its height is set from `height`; background #0e0e10; you fill it). Center or left-align content as you see fit; the left edge sits right of the sidebar.
- `ctx.act(name, arg)` applies formatting to the user's current text selection. Names: 'pocket','hat','block','tag','analytic','undertag','cite','e' (emphasis),'u' (underline),'clear','h' (highlight; arg = one of 'cyan','yellow','green','magenta','blue','red'), 'fontColor' (arg = css color), 'bigger','smaller','send'.
- `ctx.timer` = { T, fmt, toggleSpeech, paintTimer }.
